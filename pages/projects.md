- [mica](https://akonwi.io/mica/)

  A front-end library built from custom element tags, native HTML elements, and CSS. Custom elements, native behavior, nearly no JavaScript — the browser provides the behavior, not a runtime. This site is built with it.

- [Ard](https://ard.run)

  A programming language I'm building. Simple and statically typed, with direct Go interop — this site's generator is written in it.

- [Kit](https://akonwi.io/kit)

  A coding assistant for the terminal. Customizable through user-owned files: settings, themes, skills, prompt commands, and MCP support.

- [Git-plus](http://atom.io/packages/git-plus)

  Package for Github's atom editor. It allows doing git-y stuff from the editor without a terminal. As a vim user, I'm very used to Tim Pope's [vim-fugitive](http://github.com/tpope/vim-fugitive) and wanted that same feel for atom.
